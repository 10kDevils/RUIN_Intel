# RUIN Intel (retired)

> **Retired in October 2026.** Intel's job, reacting to something happening in the world, is what RUIN Muster already does, so it moved there: the sighting report (enemy group, under attack, world boss, rare, buff drop), the 30-minute feed, map pins, and the world boss and buff timers are on **RUIN Muster** 0.3.4's *Sightings* and *Timers* pages. Starting a group from a sighting is *Find group*, which lists you in **RUIN Finder** 0.3.2. `/intel ...` still works (Muster answers it), and your saved reports and timers are copied to Muster once. Disable or remove this addon.
